─────────────────────────────────────────────────────────────────
5A. LIVE PRICE DATA — Yahoo Finance
─────────────────────────────────────────────────────────────────
  Endpoint : https://query1.finance.yahoo.com/v8/finance/chart/{symbol}
  Params   : interval=1d&range=5d&includePrePost=true
  Auth     : None (public API, rate-limited)
  Returns  : open, close, high, low, volume, previousClose
  Via Proxy: Cloudflare Workers (primary) → CodeTabs (fallback) — CORS bypass
  Used By  : Dashboard ticker strip, hero price cards, news page

  Symbols tracked:
    XAU=F     — Gold (spot)
    XAG=F     — Silver (spot)
    EURUSD=X  — Euro / US Dollar
    GBPUSD=X  — British Pound / US Dollar
    USDJPY=X  — US Dollar / Japanese Yen
    USDCHF=X  — US Dollar / Swiss Franc
    AUDUSD=X  — Australian Dollar / US Dollar
    USDCAD=X  — US Dollar / Canadian Dollar
    DX-Y.NYB  — US Dollar Index (DXY)
    ^VIX      — CBOE Volatility Index
    BTC-USD   — Bitcoin / US Dollar
    GC=F      — Gold Futures (COMEX)
    CL=F      — Crude Oil WTI Futures
    ^GSPC     — S&P 500 Index

─────────────────────────────────────────────────────────────────
5B. CORS PROXY — Cloudflare Workers
─────────────────────────────────────────────────────────────────
  Primary  : https://forex-desk-proxy.zreik111.workers.dev/?url={encodedURL}
  Fallback : https://api.codetabs.com/v1/proxy/?quest={url}
  Purpose  : Bypass browser CORS restrictions for Yahoo Finance, Forex Factory,
             BabyPips scraping, CBOE data scraping

─────────────────────────────────────────────────────────────────
5C. NEWS AGGREGATION — RSS via RSS2JSON
─────────────────────────────────────────────────────────────────
  RSS-to-JSON converter: https://api.rss2json.com/v1/api.json?rss_url={encoded}&count=5
  Auth     : None (public tier, rate-limited)
  Used By  : news.html, dashboard.html (gold news widget)

  RSS Feeds:
    Kitco Gold News    : https://www.kitco.com/rss/kitco-news.rss

    Investing.com Gold : https://www.investing.com/rss/commodities_Gold.rss
    DailyFX Gold       : https://www.dailyfx.com/feeds/gold

─────────────────────────────────────────────────────────────────
5D. ECONOMIC CALENDAR — MyFXBook
─────────────────────────────────────────────────────────────────
  Endpoint : https://www.myfxbook.com/api/get-economic-calendar.json
  Params   : start={YYYY-MM-DD}&end={YYYY-MM-DD}
  Auth     : None (public API)
  Returns  : event name, forecast, actual, previous, impact (low/medium/high), country
  Used By  : calendar.html

─────────────────────────────────────────────────────────────────
5E. ECONOMIC CALENDAR — BabyPips (HTML scrape)
─────────────────────────────────────────────────────────────────
  URL      : https://www.babypips.com/economic-calendar?week={weekStr}
  Fetched via proxy (CORS)
  Returns  : HTML page — scrape for event rows
  Fallback : Forex Factory XML (see 5F)
  Used By  : calendar.html

─────────────────────────────────────────────────────────────────
5F. ECONOMIC CALENDAR — Forex Factory XML
─────────────────────────────────────────────────────────────────
  Endpoint : https://nfs.faireconomy.media/ff_calendar_thisweek.xml
  Format   : RSS/XML
  Auth     : None
  Used By  : calendar.html (fallback when BabyPips/MyFXBook unavailable)

─────────────────────────────────────────────────────────────────
5G. FEAR & GREED INDEX — alternative.me
─────────────────────────────────────────────────────────────────
  Endpoint : https://api.alternative.me/fng/?limit=35
  Auth     : None (public API)
  Returns  : Daily score (0–100), classification, timestamp (35 days history)
  Used By  : Dashboard (Fear & Greed gauge widget)

─────────────────────────────────────────────────────────────────
5H. REAL YIELD / INFLATION — FRED (Federal Reserve)
─────────────────────────────────────────────────────────────────
  Endpoint : https://fred.stlouisfed.org/graph/fredgraph.csv?id=DFII10&vintage_date={date}
  Series   : DFII10 — 10-Year Treasury Inflation-Indexed Security yield
  Auth     : None (public)
  Returns  : CSV with date,value columns
  Used By  : Dashboard (Real Yield & Macro Regime panel)

─────────────────────────────────────────────────────────────────
5I. OPTIONS SENTIMENT — CBOE
─────────────────────────────────────────────────────────────────
  URL      : https://www.cboe.com/us/options/market_statistics/daily/
  Method   : HTML scrape via CodeTabs proxy
  Returns  : Put/Call ratio data scraped from daily stats table
  Used By  : Dashboard (Options Sentiment widget)

─────────────────────────────────────────────────────────────────
5J. CHARTING — TradingView Widget Embed
─────────────────────────────────────────────────────────────────
  URL Template:
    https://www.tradingview.com/widgetembed/?frameElementId=tvChart
    &symbol={sym}&interval={interval}&theme=dark&style=1
    &studies=BB@tv-basicstudies,RSI@tv-basicstudies,MACD@tv-basicstudies
    &timezone=exchange&locale=en
  Auth     : None (public embed)
  Returns  : Interactive iframe chart
  Symbols  : XAUUSD, EURUSD, GBPUSD, USDJPY, DXY, BTCUSD, USOIL, SPX500USD
  Intervals: 1, 5, 15, 60, 240, D, W
  Used By  : Dashboard (main chart panel, switchable symbol + timeframe)

─────────────────────────────────────────────────────────────────
5K. PRICE ALERTS — Telegram Bot API
─────────────────────────────────────────────────────────────────
  Endpoint : https://api.telegram.org/bot{TOKEN}/sendMessage
  Method   : POST
  Body     : { chat_id, text, parse_mode: 'HTML' }
  Auth     : User-supplied Bot Token + Chat ID (stored in localStorage)
  Returns  : Telegram delivery confirmation
  Used By  : Dashboard (Alerts panel — notify when price level is hit)

shared.js — FUNCTIONS
────────────────────
  inject()            Injects site header, footer, and 4 blob divs (.lx-blob b1–b4)
                      into the DOM. Called once on DOMContentLoaded for all app pages.

  initTheme()         Reads localStorage('fxdesk_theme_v1'); calls applyTheme().
                      Default: dark if no preference saved.

  applyTheme(dark)    Toggles 'light-mode' class on BOTH document.body AND
                      document.documentElement (html element). Updates theme button
                      icon (🌙 = dark, ☀️ = light). Saves preference to localStorage.

  toggleTheme()       Public API — called by header theme button click handler.

  initSearch()        Attaches '/' keyboard shortcut for search focus.
                      Populates SEARCH_INDEX with page names and labels.
                      Shows dropdown results on input.

  setupSearch(inp,res) Handles arrow key navigation + Enter to navigate in results.

  toggleMobile()      Opens/closes mobile nav slide-down panel.
  toggleMobileSearch() Shows/hides mobile search overlay.

  initToast()         Creates the toast stack container (#fxToastStack) with
                      aria-live="polite", max 3 visible toasts.

  toast(msg, type, duration)  Shows a dismissible toast notification.
                              type: 'success' | 'error' | 'info'
                              duration: default 4000ms

  tickClock()         Updates #hdrTime element with live UTC time every 1s.

  initPWA()           Registers sw.js service worker. Adds <link rel="manifest">,
                      <link rel="icon">, <link rel="apple-touch-icon"> to <head>.
                      Listens for 'updatefound' event; shows toast when new version
                      of the app is ready.

  buildHeader()       Returns HTML string for the full site header (detects current
                      page from URL to set the active nav link).

  buildFooter()       Returns HTML string for site footer.

  Spotlight tracking:
    addSpots()        Injects a .lx-spot div as the first child of every
                      .card, .cal-card, .enews-card element.
    mousemove listener Updates --mx / --my CSS custom properties on each card
                      to position the mouse-tracking radial gradient.
                      Throttled with requestAnimationFrame to prevent scroll lag.
                      Uses e.target at event time (no layout read in event handler).

12. KNOWN LIMITATIONS / NOTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  • Yahoo Finance API is unofficial/undocumented. It may break or rate-limit
    without notice. The Cloudflare Worker proxy provides a buffer.

  • RSS2JSON free tier is rate-limited (~60 requests/hour). Cache is used to
    mitigate this (news articles are cached per session).

  • All trade journal + portfolio data lives in localStorage only —
    no cloud backup. Clearing browser data loses all entries.

  • Telegram alerts require the user to manually create a Telegram Bot via
    @BotFather and supply the token + chat ID in the dashboard alerts panel.

  • index.html and landing.html do NOT use shared.js or shared.css —
    they are fully standalone with all styles and scripts inline. The theme
    toggle on those pages does NOT persist between sessions (no localStorage
    integration on those two standalone pages).

  • The TradingView chart is a sandboxed iframe embed. It does not
    communicate with the surrounding page beyond symbol/interval URL params.

  • BabyPips and CBOE data are HTML scrapes — they are fragile and may
    break if those sites change their markup.
